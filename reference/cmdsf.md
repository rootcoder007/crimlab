# Classical (metric) multidimensional scaling

Torgerson scaling: the leading eigenvectors of the double-centred
squared distances
([`dblctr()`](https://rootcoder007.github.io/crimlab/reference/dblctr.md)),
each scaled by the square root of its eigenvalue (negative ones set to
0). The fit is Mardia's criterion, the kept positive eigenvalues over
the sum of all absolute ones; the stress is Kruskal's stress-1 against
the positive distances. The sign of each dimension is arbitrary.

## Usage

``` r
cmdsf(D, ndim = 2)
```

## Arguments

- D:

  A symmetric matrix of distances.

- ndim:

  The number of dimensions.

## Value

A list of class `cmdsf`: `coords`, `eigen` (the first `ndim`
eigenvalues), `stress`, `fit` and `B`.

## References

Torgerson, W. S. (1952). Multidimensional scaling: I. Theory and method.
*Psychometrika*, 17(4), 401-419.
[doi:10.1007/BF02288916](https://doi.org/10.1007/BF02288916)

Mardia, K. V. (1978). Some properties of classical multi-dimensional
scaling. *Communications in Statistics - Theory and Methods*, 7(13),
1233-1241.
