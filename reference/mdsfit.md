# Fit of a scaling by its eigenvalues

Mardia's criterion: the share of each dimension, its eigenvalue (0 when
negative) over the sum of the absolute values of all eigenvalues, and
the cumulative shares.

## Usage

``` r
mdsfit(ev)
```

## Arguments

- ev:

  The eigenvalues.

## Value

A list of class `mdsfit`: `fit`, `cumfit` and `ev` (empty fits when
every eigenvalue is 0).

## References

Mardia, K. V. (1978). Some properties of classical multi-dimensional
scaling. *Communications in Statistics - Theory and Methods*, 7(13),
1233-1241.
