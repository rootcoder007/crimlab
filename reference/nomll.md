# NOMINATE log-likelihood and classification

The log-likelihood of the observed votes under the probabilities of
[`nomutl()`](https://rootcoder007.github.io/crimlab/reference/nomutl.md)
(clamped to \\\[10^{-10}, 1 - 10^{-10}\]\\) and `gmp`, the share of
votes the model classifies correctly.

## Usage

``` r
nomll(votes, x, zy, zn, beta = 15, w = NULL)
```

## Arguments

- votes:

  A legislator-by-vote matrix: 1 yea, 0 nay, `NA` absent.

- x:

  Legislators' ideal points (legislators by dimensions).

- zy:

  The yea outcomes (votes by dimensions).

- zn:

  The nay outcomes (votes by dimensions).

- beta:

  The signal-to-noise ratio.

- w:

  `NULL` for weights of 1, or one weight per dimension.

## Value

A list of class `nomll`: `loglik`, `gmp`, `correct` and `total`.

## References

Poole, K. T. and Rosenthal, H. (1997). *Congress: A Political-Economic
History of Roll Call Voting*. Oxford University Press.

## Examples

``` r
set.seed(1)
v <- matrix(rbinom(20, 1, 0.5), 4, 5)
nomll(v, matrix(rnorm(4)), matrix(rnorm(5)), matrix(rnorm(5)))
#> nomll:
#>   loglik  -48.178
#>   gmp     0.6
#>   correct 12
#>   total   20
```
