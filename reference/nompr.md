# One NOMINATE vote probability

The probability of a yea of
[`nomutl()`](https://rootcoder007.github.io/crimlab/reference/nomutl.md)
for one legislator and one vote.

## Usage

``` r
nompr(x, zy, zn, beta = 15, w = NULL)
```

## Arguments

- x:

  The ideal point (one value per dimension).

- zy:

  The yea outcome.

- zn:

  The nay outcome.

- beta:

  The signal-to-noise ratio.

- w:

  `NULL` for weights of 1, or one weight per dimension.

## Value

A list of class `nompr` with `prob`.

## References

Poole, K. T. and Rosenthal, H. (1985). A spatial model for legislative
roll call analysis. *American Journal of Political Science*, 29(2),
357-384. [doi:10.2307/2111172](https://doi.org/10.2307/2111172)
