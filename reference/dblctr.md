# Double-centre a distance matrix

\\B = -\frac{1}{2} H D^{(2)} H\\ with \\H = I - n^{-1} 1 1'\\ and
\\D^{(2)}\\ the squared distances: the inner-product matrix of classical
scaling (Torgerson 1952).

## Usage

``` r
dblctr(D)
```

## Arguments

- D:

  A symmetric matrix of distances.

## Value

A list of class `dblctr` with the matrix `B`.

## References

Torgerson, W. S. (1952). Multidimensional scaling: I. Theory and method.
*Psychometrika*, 17(4), 401-419.
[doi:10.1007/BF02288916](https://doi.org/10.1007/BF02288916)

## Examples

``` r
D <- as.matrix(dist(cbind(c(0, 1, 3, 4), c(0, 1, 0, 2))))
dblctr(D)$B
#>         [,1]    [,2]    [,3]    [,4]
#> [1,]  4.5625  1.8125 -1.4375 -4.9375
#> [2,]  1.8125  1.0625 -1.1875 -1.6875
#> [3,] -1.4375 -1.1875  1.5625  1.0625
#> [4,] -4.9375 -1.6875  1.0625  5.5625
```
