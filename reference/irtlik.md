# Binary IRT likelihood

The log-likelihood of the votes under the probit item response model of
Clinton, Jackman and Rivers (2004), \\P(y\_{ij} = 1) = \Phi(\beta_j'
x_i - \alpha_j)\\ (clamped to \\\[10^{-10}, 1 - 10^{-10}\]\\), with the
share of votes classified correctly.

## Usage

``` r
irtlik(votes, x, alpha, beta)
```

## Arguments

- votes:

  A legislator-by-vote matrix: 1 yea, 0 nay, `NA` absent.

- x:

  Ideal points (legislators by dimensions).

- alpha:

  One difficulty per vote.

- beta:

  Discriminations (votes by dimensions).

## Value

A list of class `irtlik`: `loglik`, `prob` (0 where absent), `correct`,
`total` and `accuracy`.

## References

Clinton, J., Jackman, S. and Rivers, D. (2004). The statistical analysis
of roll call data. *American Political Science Review*, 98(2), 355-370.
[doi:10.1017/S0003055404001194](https://doi.org/10.1017/S0003055404001194)

``` r
set.seed(1)
v <- matrix(rbinom(20, 1, 0.5), 4, 5)
irtlik(v, matrix(rnorm(4)), rep(0, 5), matrix(rnorm(5)))$loglik
#> [1] -22.8751
```
