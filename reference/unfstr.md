# Stress of an unfolding

The weighted sum of squared differences between the distances from
respondents to stimuli in a configuration and the observed
dissimilarities, over the observed cells.

## Usage

``` r
unfstr(xr, xs, D, w = NULL)
```

## Arguments

- xr:

  Respondent coordinates (respondents by dimensions).

- xs:

  Stimulus coordinates (stimuli by dimensions).

- D:

  The respondent-by-stimulus dissimilarities, `NA` for missing.

- w:

  `NULL` for equal weights, or a matrix of weights like `D`.

## Value

A list of class `unfstr` with `stress`.

## References

Coombs, C. H. (1964). *A Theory of Data*. Wiley.
