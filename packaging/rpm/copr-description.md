**crimlab**: statistical methods for criminology and sociolegal research
(courts, corrections, policing, forensic science, disparities, the
analysis of crime places), computed in a compiled C++17 core. This
repository carries the `crimlab` command and the library libcrimlab.

Source, documentation and releases: https://github.com/rootcoder007/crimlab
